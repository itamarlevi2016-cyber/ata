# קול בטוח: מסמך תכונות ומפרט

מסמך זה מתאר את כל מה שהאתר "קול בטוח" עושה ואיך הוא בנוי. אפשר להעביר אותו כמו שהוא לכלי בינה מלאכותית, למפתח או למעצב, כדי לבנות או להרחיב אתר דומה.

## 1. תקציר

אתר חינמי בעברית ללימוד פיתוח קול, שלב אחרי שלב, לאנשים שמדברים מול קהל. מדריך אותו ר' דוד, דמות מצוירת ומונפשת שמדברת ומדגימה כל תרגיל.

- **סוג:** אתר סטטי לגמרי. אין שרת, אין בסיס נתונים, אין הרשמה ואין בניית קוד.
- **פרטיות:** המיקרופון מעובד בדפדפן בלבד. שום הקלטה לא נשמרת ולא נשלחת. ההתקדמות נשמרת רק בדפדפן של המשתמש.
- **פרסום:** GitHub Pages, Netlify, Cloudflare Pages או כל אחסון קבצים.
- **קהל יעד:** אנשים שמדברים בציבור (מרצים, מנחים, דוברים, מורים).

### מבנה שלב

```js
{ t: "breath",          // סוג השלב (ראו למטה)
  act: "belly",         // התנועה שר' דוד מדגים
  say: "…",             // ההסבר שמוצג בבועת הדיבור ומוקרא
  title: "…",           // כותרת (לשלבי הסבר)
  points: ["…", "…"],   // נקודות, מוצגות ומוקראות
  mood: "cheer" }       // אופציונלי: מצב רוח לדמות
```

### סוגי שלבים

| סוג | מה זה | שדות נוספים |
|---|---|---|
| `say` | הסבר, אפשר עם כותרת ונקודות | `title`, `points` |
| `range` | בחירת טווח קול (נמוך, בינוני, גבוה) עם צליל לדוגמה | |
| `breath` | נשימה מודרכת: עיגול שגדל ומתכווץ וספירה לאחור | `pattern: [[תווית, שניות, "in"/"hold"/"out"]]`, `cycles` |
| `timer` | טיימר עם טבעת התקדמות וצלצול בסיום | `secs`, `label` |
| `stopwatch` | שעון עצר לנשיפה ארוכה, עם שיא אישי | `goal` |
| `scale` | סולם צלילים: מנגן, מדגיש כל צליל, אפשר להעלות ולהוריד גובה | `notes` (הפרשי חצאי טונים), `syll`, `mic` |
| `glide` | סירנה: צליל שעולה ויורד, עם נקודה שנעה על קשת | `from`, `to`, `secs`, `mic` |
| `repeat` | חזרות על משפטים בכמה סבבים (לאט, רגיל, מהר), עם תווית ונקודות התקדמות | `items`, `passes` |
| `read` | קריאה בקול עם סימוני הפסקה והדגשה | `text` |
| `meter` | מד קול חי בתוך השיעור | `mode`, `optional`, `hint` |

**סימון בטקסט:** `*מילה*` מדגיש, `/` הפסקה קצרה, `//` הפסקה ארוכה.

## 4. רכיבי תרגול ויכולות

- **נשימה מודרכת:** עיגול מונפש לפי שאיפה, החזקה ונשיפה. הדמות נושמת יחד איתו.
- **צלילי הדגמה:** צליל רך שנוצר בדפדפן (Web Audio, צליל עם הרמוניות עדינות). טווח הקול נבחר פעם אחת (נמוך = לה2, בינוני = מי3, גבוה = לה3) וניתן להזיז בחצי טון.
- **מד קול (`js/meter.js`):**
  - **גובה צליל:** זיהוי בקורלציה עצמית על 70 עד 700 הרץ, מציג את שם הצליל בסולפז' עברי (דו, רה, מי…), הרץ, וסנטים.
  - **מד כוונון:** מחוון שמראה כמה הצליל קרוב לצליל המדויק.
  - **עוצמה:** פס עוצמה עם מחוון רגישות.
  - **גרף:** ציר זמן של 8 שניות של גובה הצליל.
  - **שליחה:** כל העיבוד בדפדפן.
- **צלילי ייחוס (עמוד כלים):** מקלדת של 13 צלילים בשלוש אוקטבות.
- **מד קול כמשימה:** נחשב כמשימה שהושלמה אחרי 3 שניות של צליל.

## 5. ר' דוד, המאמן

דמות מצוירת ומונפשת, מבוססת על איור שסופק על ידי בעל האתר.

- **שכבות:** האיור חתוך לשכבות רקע, גוף וראש (`assets/char/`), ומורכב כ-SVG ב-`js/coach.js`.
- **אנימציות:** נשימה, מצמוץ, הטיית ראש, הרמת כתפיים, פה שמדבר (צורות פה: סגור, פתוח קטן, פתוח רחב, חיוך עם שיניים, "או").
- **תנועות (`act`)** שמופיעות בכיתוב "מדגים: …": עמידה יציבה, גלגול כתפיים, הטיית צוואר, שחרור הלסת, נשימה אל הבטן, המהום, רטט, צליל דרך קשית, סירנה, סולם, הקרנה, אנחה, תנועות בפה פתוח, ועוד תנועות כלליות (שלום, הצבעה, פריסת ידיים, חגיגה).
- **אפקטים:** חיצים שמושכים למעלה, הילה סביב הידיים בנשימה, צלילים צפים, גלי קול, קשית, ניצוצות בחגיגה.
- **תמונות תנוחה (`assets/poses/`):** עשר תמונות של אותה דמות בתנוחות ידיים (שלום, הצבעה, פריסת ידיים, כף יד, לסת, קשית, המהום, סירנה, הקרנה, חגיגה). הן מוצגות במקום הדמות המונפשת בשלבים המתאימים, ובתנוחות רגועות מצויר מעליהן פה שמדבר. תמונה חדשה מוסיפים לתיקייה ולרשימה `manifest.json`.

## 6. הקראה (קריינות)

- **מה מוקרא:** בכל שלב הכותרת, ההסבר וכל הנקודות. סמלים ואימוג'י מוסרים, ו"ר'" מוקרא "רבי".
- **הקלטות אנושיות:** קבצי `audio/<שיעור>-<אינדקס>.mp3` ורשימה `audio/manifest.json` עם גיבוב (hash) של הטקסט. ההקלטה מתנגנת רק אם הטקסט לא השתנה מאז שנוצרה.
- **גיבוי:** הקראת הדפדפן בעברית, בקטעים קצרים (משפט אחרי משפט), עם עדיפות לקול גברי.
- **בקרה:** מתג קריינות, בחירת מהירות (איטי, רגיל, מהיר), וכפתור 🔊 להשמעה חוזרת.
- **מילון הגייה:** `js/pronounce.js`, זוגות של מילה והגייה (אפשר עם ניקוד).
- **יצירת הקלטות:** `tools/generate_audio.py` ו-`.github/workflows/audio.yml` מייצרים אותן אוטומטית ב-GitHub בכל שינוי בתוכן. שירותים נתמכים (לפי הסדר): Azure Speech (`he-IL-AvriNeural`), OpenAI TTS, `edge-tts` (חינמי, לא רשמי, חסום לרוב).

## 7. נקודות, חזרות והתקדמות

הכול נשמר ב-`localStorage` של הדפדפן (מפתח `kol-bothe:v1`).

- **משימה:** כל תרגיל אינטראקטיבי הוא משימה: נשימה, טיימר, שעון עצר, סולם, סירנה, חזרות, קריאה ומד קול. סיום משימה מזכה ב-**10 נקודות**, **פעם אחת ביום לכל משימה** (כדי שאי אפשר יהיה לצבור נקודות בלי סוף על אותו תרגיל).
- **חזרה:** נספרת בסבב נשימה שהושלם, טיימר שהסתיים, משפט שנקרא, ניגון סולם או סירנה שהסתיימו, קריאה שהושלמה ומשימת מד קול.
- **רמות:** מתחיל (0), מתחמם (50), מתרגל (150), דובר בטוח (300), דובר מקצועי (600), אמן הקול (1000).
- **רצף ימים:** מספר הימים הרצופים של תרגול, ושיא הרצף.
- **עמוד ההתקדמות:** רמה עם פס התקדמות לרמה הבאה, שישה כרטיסי נתונים (שיעורים שהושלמו, חזרות, משימות, ימים ברצף, ימי תרגול, שיא נשיפה), גרף נקודות ל-14 ימים, פירוט לכל שיעור, וכפתור איפוס.
- **במהלך שיעור:** מונה משימות ("⭐ 2/5"), הודעת "+10 נקודות" בסיום משימה, ומסך סיום עם סיכום.

## 8. עיצוב וחוויית משתמש

- **שפה:** עברית מימין לשמאל. גופן Heebo (Google Fonts) עם גיבוי למערכת.
- **צבעים:** טורקיז (`#1f7a83`) כצבע ראשי, קורל (`#ff7a59`) לפעולות, צהוב-כתום לנקודות. רקע בז' חם.
- **מצב כהה:** אוטומטי לפי הגדרות המכשיר.
- **תצוגה:** מותאם לטלפון ולמחשב. בטלפון הדמות קטנה והתפריט מצטמצם בתוך שיעור.
- **נגישות:** קישור "דלגו לתוכן", תוויות ARIA, חיווי פוקוס, התחשבות בהעדפת "הפחתת תנועה", ניווט מקלדת בשיעור (חצים).
- **פשטות:** כפתור ראשי אחד בכל שלב ("לשלב הבא"), התקדמות ויזואלית של השלבים, ושמירה אוטומטית.

## 9. מבנה טכני

JavaScript טהור (ES modules), בלי build ובלי תלויות.

```
index.html            מעטפת, ניווט וכותרת
css/style.css         כל העיצוב
js/app.js             ניווט (#/...) ועמודי בית, קורס, כלים, התקדמות, בריאות
js/data.js            תוכן השיעורים
js/steps.js           רכיבי התרגילים
js/player.js          נגן השיעורים
js/coach.js           הדמות, התנועות והאנימציות
js/narration.js       מה מוקרא בכל שלב
js/voice.js           ההשמעה (הקלטות או הקראת דפדפן)
js/pronounce.js       מילון הגייה
js/audio.js           צלילים, מיקרופון והקראה
js/meter.js, pitch.js מד קול וזיהוי גובה צליל
js/progress.js        שמירה, נקודות, רמות וסטטיסטיקה
assets/char, poses    שכבות הדמות ותנוחות
audio/                הקלטות mp3
tools/                יצירת הקלטות
tests/                בדיקות (node --test)
```

- **בדיקות:** 13 בדיקות אוטומטיות (זיהוי גובה צליל, נקודות ורמות, רצף ימים, הקראה, כיסוי תנועות).
- **API של הדפדפן שנדרשים:** Web Audio, `getUserMedia`, `speechSynthesis`, `localStorage`, SVG.
- **מיקרופון:** דורש כתובת מאובטחת (https או localhost).

## 10. מגבלות ידועות

- ההקראה בקול אנושי דורשת מפתח של שירות הקראה (Azure או OpenAI). בלעדיו נשמע הקול הרובוטי של הדפדפן.
- איכות ההגייה של שירותי ההקראה לא נבדקה, ויש להקשיב ולהוסיף מילים למילון ההגייה.
- ההתקדמות נשמרת בדפדפן אחד ובמכשיר אחד. אין חשבונות ואין סנכרון בין מכשירים.
- התוכן הוא תרגול כללי ובטוח. מומלץ שמורה מקצועי לקול יעבור עליו. באתר יש הסתייגות רפואית.
- תמונות התנוחה נוצרו בכלי נפרד, והפרופורציות שלהן מעט שונות מהאיור המקורי.

## 11. רעיונות להמשך

- הקלטה עצמית והשמעה חוזרת (בלי שמירה בשרת)
- מד קצב דיבור (מילים לדקה) ותרגול מטקסט שמדביקים
- שיעורים נוספים: התמודדות עם התרגשות, מילות מילוי, דיבור בזום, סיפור סיפור
- תעודת סיום ושיתוף ההתקדמות
- תזכורת יומית והתקנה כאפליקציה (PWA)
- חשבונות וסנכרון בין מכשירים (דורש שרת)
