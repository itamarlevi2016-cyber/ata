# ממלכת האנגלית — English Quest

משחק לימוד אנגלית לילדים בגיל הגן ותחילת בית הספר: 26 אותיות בשישה מסעות,
משפחות צלילים, אוצר מילים, משחקי זיכרון והקשבה, ותחרות משפחתית.
אפליקציית דפדפן בלבד, ללא שרת וללא חשבון. ההתקדמות נשמרת במכשיר,
והאתר עובד גם ללא חיבור לאינטרנט אחרי הטעינה הראשונה.

## מבנה

| נתיב | תפקיד |
|---|---|
| `app/index.html` | דף הכניסה היחיד |
| `app/app.js` | שכבת הבסיס: מילים, חידונים, משחקים, פרופילים, אזור הורים |
| `app/quest.js` | שכבת "ממלכת האנגלית": מסעות אותיות, צלילים, נעילת שלבים, נעילת הורים |
| `app/style.css`, `app/quest.css` | עיצוב |
| `app/sw.js`, `app/manifest.webmanifest` | התקנה למסך הבית ועבודה אופליינית |
| `app/assets/` | תמונות ואייקונים |
| `Start.cmd`, `Install-Windows.cmd`, `READ-ME.html` | הפעלה והתקנה במחשב Windows ללא אינטרנט |

## הרצה מקומית

פותחים את `app/index.html` בדפדפן, או מריצים שרת סטטי מתוך `app/`:

```bash
cd app && python3 -m http.server 8080
```

ההקראה משתמשת בקולות האנגלית של המכשיר (Web Speech API). את הקול המועדף
בוחרים באזור ההורים.

## פריסה

כל דחיפה ל-`main` שמשנה את `app/` מפרסמת את האתר ל-GitHub Pages דרך
`.github/workflows/pages.yml`. בהגדרות המאגר, תחת Pages, מקור הפריסה צריך
להיות "GitHub Actions".

חשוב: ה-service worker שומר עותק של הקבצים במכשיר. אחרי כל שינוי בקבצי
`app/` יש להעלות את מספר הגרסה בשורה הראשונה של `app/sw.js`, אחרת
משתמשים קיימים יראו את הגרסה הישנה.

## גיבוי התקדמות

באזור ההורים יש הורדת גיבוי ושחזור (קובץ JSON). מומלץ לגבות לפני מעבר
מכשיר או ניקוי נתוני דפדפן.
