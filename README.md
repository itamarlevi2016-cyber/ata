# תמלול עברית — מקומי ואמין

תוכנה שמותקנת על המחשב ומתמללת הקלטות בעברית. התמלול נעשה כולו על המחשב שלכם, בלי שליחת ההקלטות לשום שירות חיצוני. נדרש אינטרנט רק בהתקנה (להורדת המודלים) ובתמלול מקישור (להורדת השמע מהאתר).

## מה יש בה

- העלאת קבצי שמע ווידאו בכל הפורמטים הנפוצים (mp3, wav, m4a, ogg, flac, mp4, mkv ועוד)
- תמלול מקישור: יוטיוב, פייסבוק ומאות אתרים נוספים (דרך yt-dlp)
- מודל Whisper שאומן במיוחד לעברית ([ivrit.ai](https://www.ivrit.ai))
- הגדרות שמונעות "הזיות" של המודל: סינון שקט (VAD), חיפוש קרן, וזיהוי חזרות
- סימון מילים שהמודל פחות בטוח בהן, כדי שתדעו מה לבדוק
- לחיצה על מילה מנגנת אותה, ולחיצה כפולה על פסקה פותחת עריכה
- זיהוי דוברים (אופציונלי), עם שינוי שמות הדוברים
- ייצוא ל-Word, לטקסט ולכתוביות SRT

## דרישות

- **Python בגרסה 3.10 עד 3.12**: מורידים מ-[python.org](https://www.python.org/downloads/). בהתקנה ב-Windows מסמנים את **"Add Python to PATH"**.
- **כרטיס מסך NVIDIA (מומלץ מאוד)**. עם כרטיס כזה, שעת הקלטה מתומללת בכמה דקות. בלעדיו התוכנה עובדת על המעבד הרגיל, אבל שעת הקלטה עלולה לקחת שעה או יותר.
- **מקום פנוי בדיסק**: כ-5GB (וכ-8GB עם זיהוי דוברים).

## התקנה (Windows)

1. מורידים את הפרויקט (Code → Download ZIP) ומחלצים לתיקייה.
2. לחיצה כפולה על **`install.bat`**. הקובץ מתקין את הרכיבים ומוריד את מודל התמלול (כ-1.6GB, פעם אחת בלבד).
3. לחיצה כפולה על **`run.bat`**. האתר ייפתח בדפדפן בכתובת `http://localhost:8000`.

ב-Mac או Linux: `./install.sh` ואחר כך `./run.sh`.

## זיהוי דוברים (אופציונלי)

מודל זיהוי הדוברים (pyannote) דורש אישור חד-פעמי באתר Hugging Face:

1. נרשמים בחינם ל-[huggingface.co](https://huggingface.co).
2. מאשרים את תנאי השימוש בשני הדפים האלה:
   [speaker-diarization-3.1](https://huggingface.co/pyannote/speaker-diarization-3.1),
   [segmentation-3.0](https://huggingface.co/pyannote/segmentation-3.0).
3. יוצרים טוקן קריאה ב-[הגדרות הטוקנים](https://huggingface.co/settings/tokens).
4. מעתיקים את הקובץ `.env.example` לקובץ חדש בשם `.env` וכותבים בו `HF_TOKEN=הטוקן_שלכם`.
5. מריצים את **`install-diarization.bat`**.

אחרי ההורדה הראשונה זיהוי הדוברים עובד גם בלי אינטרנט.

## מחשב בלי כרטיס NVIDIA

גם כרטיס גרפי מובנה, כמו Intel UHD Graphics, נחשב "בלי כרטיס NVIDIA". במקרה כזה התמלול רץ על המעבד, וזה עובד, רק לאט יותר:

- **מצב "מדויק"** (ברירת המחדל): הכי אמין. לוקח בערך פי 1 עד פי 3 מאורך ההקלטה, תלוי במחשב.
- **מצב "מהיר"**: בערך פי 2 מהר יותר, ומעט פחות מדויק.
- בזמן התמלול מוצגת הערכה של הזמן שנותר.
- **זיכרון**: מומלץ לסגור דפדפנים ותוכנות כבדות. התמלול צריך כ-3GB זיכרון פנוי, ועם זיהוי דוברים צריך עוד כ-2GB.
- **מחשב נייד**: כדאי לחבר אותו לחשמל. על סוללה Windows מאט את המעבד.
- **שעת הקלטה**: אפשר להפעיל את התמלול ולהשאיר את המחשב לעבוד. אם הוא נכבה, העבודה תמשיך בהפעלה הבאה.

## תמלול בענן (אופציונלי)

אם התמלול במחשב איטי מדי, אפשר להריץ את **אותו מודל עברי של ivrit.ai** על שרת GPU שכור ב-RunPod. שעת הקלטה תתומלל כך בכמה דקות. בכל תמלול בוחרים מחדש: "במחשב" או "בענן".

**איך זה עובד:**
- התוכנה מזהה במחשב את קטעי הדיבור, ושולחת לענן רק אותם, דחוסים ומחולקים לחלקים של עד כ-10 דקות. כך משלמים רק על דיבור, והמודל לא "ממציא" טקסט בקטעים שקטים.
- כל השאר נשאר כמו בתמלול במחשב: העריכה, הייצוא והסימון של מילים לבדיקה.
- **חשוב לדעת:** במצב ענן ההקלטה נשלחת לשרת של RunPod. תמלול במחשב לא שולח שום דבר.

**הגדרה (פעם אחת):**
1. נרשמים ל-[runpod.io](https://runpod.io) וטוענים קרדיט (מינימום כ-10 דולר).
2. פותחים את [התבנית של ivrit.ai](https://www.runpod.io/console/hub/ivrit-ai/runpod-serverless), לוחצים **Deploy** ויוצרים נקודת קצה (Endpoint). אפשר להשאיר את ההגדרות כמו שהן. חשוב שהשדה Active Workers יהיה 0, כדי לא לשלם כשלא מתמללים.
3. מעתיקים את **מזהה נקודת הקצה** (Endpoint ID) מדף נקודת הקצה.
4. יוצרים **מפתח API** בהגדרות החשבון (Settings ← API Keys).
5. בקובץ `.env` כותבים:
   ```
   RUNPOD_API_KEY=המפתח_שלכם
   RUNPOD_ENDPOINT_ID=המזהה_שלכם
   ```
6. מפעילים מחדש את `run.bat`. ברשימת "מנוע" תופיע עכשיו האפשרות "בענן".

**עלות:** משלמים רק על זמן העבודה של השרת. שעת הקלטה עולה בדרך כלל פחות מדולר. בפעם הראשונה אחרי הפסקה השרת "מתעורר", וזה עלול לקחת כמה דקות.

## טיפים לאמינות

- הקלטה איכותית היא הגורם הכי משמעותי: מיקרופון קרוב, ומעט רעשי רקע ודיבור חופף.
- אם ידוע כמה דוברים יש בהקלטה, כדאי להזין את המספר. זה משפר את זיהוי הדוברים.
- מילים מסומנות בצהוב הן מילים שהמודל פחות בטוח בהן. כדאי להאזין להן ולתקן לפי הצורך.
- במחשב עם כרטיס מסך חזק אפשר לנסות את המודל הגדול (והאיטי יותר) `ivrit-ai/whisper-large-v3-ct2`. ההגדרה נעשית בקובץ `.env`.

## הגדרות

כל ההגדרות נמצאות בקובץ `.env`, ויש דוגמה בקובץ `.env.example`. כברירת מחדל האתר נגיש רק מהמחשב שעליו הוא מותקן.

## למפתחים

```
pip install -r requirements.txt pytest httpx
python -m pytest tests
```

מבנה הקוד:

- `app/transcriber.py`: התמלול
- `app/diarizer.py`: זיהוי הדוברים
- `app/downloader.py`: הורדה מקישורים
- `app/jobs.py`: תור העבודות
- `app/main.py`: השרת
- `app/static/`: הממשק
