# קול בטוח — פיתוח קול לדוברים

אתר חינמי בעברית ללימוד פיתוח קול, שלב אחרי שלב, לאנשים שמדברים מול קהל. ר' דוד, המאמן, מדריך את התרגילים.

## מה יש באתר

- **9 שיעורים קצרים:** היכרות עם הקול, יציבה, נשימה סרעפתית, חימום, דיקציה, הקרנה, תהודה, קצב והדגשה, והכנה לבמה.
- **תרגול יומי של 5 דקות.**
- **ר' דוד, דמות מונפשת** שמדברת, נושמת ומדגימה בתנועות ידיים וגוף את התרגילים: עמידה יציבה, גלגול כתפיים, הטיית צוואר, שחרור לסת, נשימה לבטן, רטט שפתיים, צליל דרך קשית, סירנה ועוד.
- **קריינות מלאה** של כל שלב: כותרת, הסבר וכל הנקודות. אם יש הקלטות קול אנושיות בתיקיית `audio` הן מתנגנות, ואחרת האתר מקריא בעזרת הקול העברי של המכשיר.
- **סטטיסטיקה ונקודות:** שיעורים שהושלמו, חזרות, משימות (10 נקודות לכל משימה, פעם ביום), רמות, רצף ימים וגרף של 14 ימים.
- **תרגילים אינטראקטיביים:** נשימה מודרכת, טיימרים, צלילים להדגמה, סולמות, סירנה, צליל דרך קשית, גלגול לשון, קירור הקול וחזרות.
- **מד קול:** מזהה את הצליל והעוצמה מהמיקרופון ומציג גרף. הכול קורה בדפדפן, שום הקלטה לא נשמרת ולא נשלחת.
- **מעקב התקדמות** ורצף ימים, שנשמרים בדפדפן בלבד.
- מצב כהה אוטומטי ותצוגה מותאמת לטלפון.

## פרסום באינטרנט

האתר סטטי לגמרי: אין שרת ואין שלב בנייה. אפשר לפרסם אותו בחינם בכמה דרכים.

### GitHub Pages
1. ב-GitHub נכנסים למאגר, ל-**Settings ← Pages**.
2. ב-**Source** בוחרים **Deploy from a branch**.
3. בוחרים את הענף ואת התיקייה **/ (root)**, ולוחצים **Save**.
4. אחרי דקה-שתיים הכתובת תופיע שם, בצורה `https://<שם-משתמש>.github.io/<שם-מאגר>/`.

### Netlify או Cloudflare Pages (בלי GitHub)
גוררים את תיקיית האתר לדף [Netlify Drop](https://app.netlify.com/drop) ומקבלים כתובת מיד.

## קול אנושי להקראה

הקראה של הדפדפן נשמעת רובוטית ולפעמים טועה בהגייה. כדי לקבל קול אנושי, האתר יודע לנגן הקלטות שנוצרות מראש בקול עברי עצבי (`he-IL-AvriNeural`, קול גברי).

- **אוטומטית ב-GitHub:** בכל פעם שמשתנה תוכן השיעורים או מילון ההגייה, תהליך אוטומטי (`.github/workflows/audio.yml`) יוצר את ההקלטות החסרות ומוסיף אותן לענף. אפשר גם להפעיל אותו ידנית מלשונית **Actions**.
- **במחשב:** `pip install edge-tts` ואז `python tools/generate_audio.py`. נדרש Node.js.
- **שירות רשמי (מומלץ לאתר ציבורי):** הגדירו סודות `AZURE_SPEECH_KEY` ו-`AZURE_SPEECH_REGION` ב-GitHub (Settings ← Secrets and variables ← Actions), והתהליך ישתמש ב-Azure Speech הרשמי, עם מכסה חינמית. בלעדיהם נעשה שימוש ב-`edge-tts`, שאינו API רשמי של Microsoft.
- **תיקון הגייה שגויה:** מוסיפים שורה ב-`js/pronounce.js` (אפשר עם ניקוד), וההקלטה של השלבים הרלוונטיים נוצרת מחדש.
- אם הקובץ של שלב לא תואם לטקסט הנוכחי, האתר מתעלם ממנו ומקריא בקול של הדפדפן.

## הרצה במחשב

```
python3 -m http.server 8000
```
ופותחים `http://localhost:8000`. המיקרופון עובד רק בכתובת מאובטחת (https) או ב-localhost, ולכן אי אפשר לפתוח את `index.html` ישירות מהקובץ.

## מבנה הקוד

| קובץ | תפקיד |
|---|---|
| `index.html` | מעטפת האתר |
| `js/data.js` | **תוכן השיעורים.** כאן עורכים טקסטים ותרגילים |
| `js/steps.js` | סוגי התרגילים (נשימה, טיימר, סולם, חזרות ועוד) |
| `js/player.js` | נגן השיעורים |
| `js/coach.js` | הדמות המצוירת, התנועות והאנימציות שלה |
| `js/narration.js`, `js/voice.js`, `js/pronounce.js` | מה מוקרא בכל שלב, ההשמעה, ומילון הגייה |
| `tools/generate_audio.py` | יצירת הקלטות הקול האנושיות (mp3) |
| `audio/` | ההקלטות שנוצרו, ורשימה (`manifest.json`) |
| `js/meter.js`, `js/pitch.js`, `js/audio.js` | מיקרופון, זיהוי גובה צליל וצלילי הדגמה |
| `js/progress.js` | שמירת התקדמות |
| `css/style.css` | העיצוב |

בדיקות: `node --test tests/core.test.mjs`

## הערה חשובה

התוכן הוא תרגול כללי ובטוח, ואינו מחליף ייעוץ רפואי או הדרכה אישית של מורה לקול. מומלץ שמורה מקצועי יעבור על התוכן לפני פרסום לקהל רחב.
