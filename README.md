# מתרגם Making of a Godol

כלי לתרגום כרך א' של *Making of a Godol* מאנגלית לעברית, עם פלט Word.
המקור הוא **תמונת העמוד**; שכבת הטקסט הסרוקה נשלחת רק כרמז, ומסומנת כלא אמינה.

## הפעלה

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...            # או: ant auth login
python -m godol.cli serve               # http://127.0.0.1:8000
```

בממשק: מעלים PDF פעם אחת, בוחרים קטע מתוך המיפוי (הקטע הבא נבחר אוטומטית), לוחצים "תרגם".
אפשר גם בשורת פקודה (זו ריצת הקבלה על 331–340):

```bash
python -m godol.cli run --pdf קמינצקי.pdf --start 331 --end 340 --chapter 3
```

הריצה נעצרת ומדווחת אם עמוד נכשל (עד 3 ניסיונות לכל עמוד, ללא המשך שקט). מה שכבר תורגם נשמר, והרצה חוזרת ממשיכה משם.

## חומרים (`materials/`)

| קובץ | מצב |
|---|---|
| `מדריך תרגום.md` | קיים. נטען כמות שהוא כהודעת מערכת בכל קריאה, עם prompt caching |
| `יומן התקדמות.md` | קיים. מתעדכן בסוף כל קטע (במצב `GODOL_MOCK=1` נכתב עותק תחת `work/` ולא היומן האמיתי) |
| `מיפוי הספר.md` | קיים. 32 קטעים עם טווחי עמודים ופרקים; הסטטוס של כל קטע נלקח מהיומן. קטע 32 (הקדמה ותודות, כמה טווחים נפרדים) נבחר ידנית. בלי הקובץ: קטעים 0–12 מהיומן |
| `שמות חדשים – סבב 1/2/2 (המשך).md` | **לא צורפו.** המילון נבנה כרגע מטבלאות המדריך. קבצים בשם `שמות חדשים*.md` נטענים אוטומטית |
| `פיילוט.docx` | **לא צורף.** בלעדיו העיצוב נבנה לפי מפרט המדריך (17×24, David 12, הערות 9.5). עם הקובץ: הסגנונות וגודל העמוד נלקחים ממנו |
| `allowed_latin.txt` (אופציונלי) | חריגים נוספים לאותיות לועזיות, שורה לפריט |

`build.js`, `apply_names.py`, `restructure.py` ו-`sections.py` לא צורפו, ולכן מומשו מחדש (ראו למטה). אם תצרף אותם, אפשר להשוות פלט.

## איך זה בנוי

```
PDF → תמונה לכל עמוד (PyMuPDF, 200 DPI) + שכבת טקסט כרמז
    → Claude (vision, JSON מובנה, המדריך ב-cache) → pages/pNNNN.json לכל עמוד
    → apply names (רשת ביטחון) → שמות חדשים לקובץ "ממתינים לאישור"
    → הרכבה (איחוד פסקאות בין עמודים, סיפור פעם אחת, הערות בסוף הפרק, נספחים)
    → Word (OOXML ישיר: הערות שוליים אמיתיות hebrew1, מתחילות מחדש בכל פרק, הערות Word של "Claude")
    → 8 בדיקות + דוח → עדכון היומן
```

- `godol/schema.py` – מבנה הפלט (heading_chapter, heading_section, body_paragraph, footnote_source, numbered_note, excursus_heading, excursus_body, review_flag) ואימות סמנטי.
- `godol/pipeline.py` – עמוד אחר עמוד, נקודות שמירה, ניסיון חוזר מוגבל, עצירה בכשל.
- `godol/assemble.py` – מחליף את `restructure.py`. `godol/docx_writer.py` – מחליף את `build.js`/`sections.py`.
- `godol/qa.py`, `godol/docx_check.py` – הבדיקות. `godol/service.py` – בניית קטע ודוח.

## בקרת איכות

הקטע נחשב "מוכן" רק כשכל 8 הבדיקות עוברות, כולל הבודק העצמאי (קריאה נפרדת שרואה רק את תמונת העמוד ואת העברית):

1. אין אותיות לועזיות (פרט לחריגי המדריך).
2. אין שאריות סימון. פירוש: `^ * £ ° § # | _ ~`, סימון פנימי שבור, סוגריים לא מאוזנים; ספרות הדבוקות לאות עברית מדווחות כהערה. נקודה וסוגריים מרובעים תקינים, והמדריך משתמש בהם.
3. מספר הערות השוליים, הכוכביות, הממוספרות והנספחים בפלט שווה לספירה של המודל מהתמונה.
4. כל עמוד מיוצג (משפט פתיחה וסיום), בלי פסקה כפולה.
5. השמות תואמים למילון; שם קיים שהמודל הציע לשנות לא משתנה והבדיקה נכשלת עד החלטה.
6. אין הערת שוליים שמופיעה כפסקה בגוף.
7. הקובץ נפתח: שלמות החבילה, XML, קשרים, הערות שוליים והערות Word, python-docx והמרה ב-LibreOffice.
8. הבודק העצמאי. נשמר לפי חתימת הטקסט, ורץ שוב רק על עמוד ששונה.

## בדיקות

```bash
python -m pytest tests
```

הבדיקות מפעילות את כל הצינור עם מודל מדומה (`GODOL_MOCK=1`). הן בודקות את התשתית, לא את איכות התרגום.

## משתני סביבה

`GODOL_MODEL` (ברירת מחדל `claude-opus-5-5`), `GODOL_EFFORT` (`high`), `GODOL_DPI` (200), `GODOL_PAGES_PER_CALL` (1–3), `GODOL_MAX_ATTEMPTS` (3), `GODOL_WORK`, `GODOL_MATERIALS`.
