# קול בטוח — הגרסה המאוחדת

אתר סטטי בעברית לתרגול קול לדוברים, עם שני מסלולים (11 שיעורי פיתוח קול, ו-5 שיעורים על דיבור איטי וברור למי שמוסר שיעור) ותרגול יומי, קריינות Cedar, ר׳ דוד, מד קול ומעקב השתתפות בדפדפן.

## מה כלול
- הדרכה, המחשה ותרגול, עם שמירת מקום והשהיית תרגיל במעבר לידע.
- לשונית הרחבת ידע בכל שלב ומידע כללי בדפי האתר.
- איור ראשי מקורי של ר׳ דוד במסגור יציב; איורי גוף מלא באזור המחשה נפרד. ההמחשות סכמטיות.
- מוזיקה כליּת שקטה, כיבוי ועוצמה נפרדת. המוזיקה נעצרת בשיעורים ובכלים. דפדפן שחוסם autoplay ידרוש לחיצה.
- משוב על נוחות ומאמץ ויישום במשפטי דיבור. נקודות מייצגות השתתפות, ולא איכות קול מדודה.

- הסבר מפורט לכל הוראה בשיעור (js/guides.js): למה עושים, צעד אחרי צעד, מה מרגישים, טעויות נפוצות ומה עושים אם קשה. נפתח מתחת להוראה בלי לעצור את התרגיל.

- מסלול "מדברים לאט וברור": מדידת קצב (מילים לדקה), קריאה עם סמן בקצב יעד, והקלטה עצמית עם מפת דיבור/שקט (js/pace.js). ההקלטה נשארת בזיכרון הדף בלבד.
- לשיעורי המסלול החדש אין עדיין הקלטות Cedar; עד שיוקלטו, ר' דוד מקריא בקול הדפדפן. התסריטים ב-review/NEW_TRACK_CEDAR_SCRIPTS.txt.

## העלאה
מעלים את index.html, .nojekyll ואת התיקיות css, js, assets ו-audio, כך ש-index.html נמצא בשורש האתר. התיקיות review, tests, tools ו-docs אינן חלק מהאתר הציבורי. אין שרת או שלב בנייה. המיקרופון דורש HTTPS או localhost.

## בדיקות
- review/visual-review.html: עיון במראה הדמות והמחשות לפי שיעור ושלב.
- review/qa.html: האזנה ל־88 קטעים, סינון סימונים טכניים, הערות וייצוא תוצאות. סימון תקינות קשור לגרסת ההקלטה.
- review/AUDIO_TECHNICAL_REVIEW_HE.md: סיכום הבדיקה הטכנית ורשימת 11 תחילות לתעדוף בהאזנה.
- review/audio-technical-audit.csv: נתוני המדידה לכל קטע.
- review/UPDATE_NOTES_HE.md: היסטוריית השיפורים ומגבלות האימות.

הרצת בדיקות קוד: npm test

## מצב האימות
בדיקות הקוד, הקישור בין תמלולים וקבצים והפענוח הטכני עברו. עדיין נדרשות בדיקת פריסה והנפשה בדפדפן אמיתי והאזנה להגייה, לחיתוכים ולהתאמה לתוכן. חלק מהניסוחים הישנים על תהודה ומשכי נשיפה דורשים עיון במסגרת ביקורת התוכן והשמע.
