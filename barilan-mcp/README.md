# חיבור שו"ת בר אילן לסוכן בינה מלאכותית (Claude)

כלי (שרת MCP) שמאפשר ל-Claude Desktop / Claude Code לחפש בתוכנת שו"ת בר אילן
שמותקנת על המחשב — **ברקע, בלי להזיז את העכבר, בלי להקליד ובלי לגנוב את הפוקוס**,
כך שאפשר להמשיך לעבוד במחשב כרגיל בזמן שהסוכן מחפש.

## איך זה עובד
הכלי לא "משתלט" על המסך. הוא מדבר עם הפקדים של התוכנה דרך ממשק הנגישות של Windows
(UI Automation): כותב לתיבת החיפוש, "לוחץ" על כפתור החיפוש בהודעה פנימית, וקורא את
רשימת התוצאות ואת הטקסט — הכל בלי עכבר ומקלדת אמיתיים.

הסוכן מקבל את הכלים:
| כלי | מה הוא עושה |
|---|---|
| `barilan_status` | בודק שהתוכנה פתוחה ונגישה |
| `barilan_search` | מריץ חיפוש ומחזיר רשימת תוצאות ממוספרת |
| `barilan_open_result` | פותח תוצאה לפי מספר ומחזיר את טקסט המקור |
| `barilan_window_text` | גיבוי: כל הטקסט שמוצג כרגע בחלון |

## התקנה (פעם אחת)
1. התקן Python 3.10+ מ-python.org (סמן "Add Python to PATH").
2. העתק את התיקייה `barilan-mcp` למחשב, למשל ל-`C:\barilan-mcp`.
3. בשורת הפקודה (cmd):
   ```
   cd C:\barilan-mcp
   pip install -r requirements.txt
   ```

## כיול (חשוב! פעם אחת)
כל תוכנה בנויה קצת אחרת, ולכן צריך לבדוק פעם אחת איך נקראים הפקדים בבר אילן 32:

1. חבר את הדיסק און קי ופתח את שו"ת בר אילן.
2. הרץ:
   ```
   cd C:\barilan-mcp
   python server.py --inspect
   ```
3. ייווצרו שלושה קבצים: `barilan_windows.txt`, `barilan_ui_uia.txt`, `barilan_ui_win32.txt`.
   **שלח אותם ל-Claude** (בשיחה הזו), והוא ייצור לך קובץ `config.json` מותאם.
4. בדיקה מהירה בלי Claude:
   ```
   python server.py --test "קריעה לאבל" --open 0
   ```

## חיבור ל-Claude Desktop
ערוך את הקובץ `%APPDATA%\Claude\claude_desktop_config.json`
(או: Settings → Developer → Edit Config) והוסף:
```json
{
  "mcpServers": {
    "bar-ilan": {
      "command": "python",
      "args": ["C:\\barilan-mcp\\server.py"]
    }
  }
}
```
סגור את Claude Desktop לגמרי (גם מהמגש ליד השעון) ופתח מחדש.

**ל-Claude Code:**
```
claude mcp add bar-ilan -- python C:\barilan-mcp\server.py
```

## טיפ: שהתוכנה לא תפריע לך בכלל
Windows מאפשר כמה "שולחנות עבודה וירטואליים":
לחץ `Win+Ctrl+D` לשולחן חדש, פתח שם את בר אילן, וחזור לשולחן שלך עם `Win+Ctrl+←`.
הסוכן ימשיך לעבוד מול התוכנה שם, ואתה לא תראה אותה בכלל.
(עדיף לא למזער את החלון — יש תוכנות שלא מעדכנות תצוגה כשהן ממוזערות.)

## הערות
- התוכנה צריכה להיות פתוחה (והדיסק און קי מחובר) כשהסוכן מחפש.
- בזמן שהסוכן מחפש, עדיף שלא תחפש בעצמך באותה תוכנה באותו רגע — אתם חולקים את אותו חלון.
- הכלי לא קורא ולא מפענח את קבצי המאגר; הוא רק מפעיל את התוכנה עצמה, כמו משתמש.
  כדאי לוודא שתנאי השימוש ברישיון מתירים זאת.
