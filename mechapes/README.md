# מחפש – חיפוש בתוך קבצים

תוכנה חינמית שרצה במחשב בלבד, בלי אינטרנט. היא מחפשת **בתוך** תוכן הקבצים (Word, PDF, Excel, PowerPoint, טקסט ועוד) בתיקיות שבחרתם.

## התקנה
אין צורך בהתקנה. יש שתי גרסאות:
- **Mechapes-portable.zip**: מחלצים לתיקייה (למשל `C:\Mechapes`) ומפעילים את `Mechapes.exe`. נפתחת מהר יותר.
- **Mechapes-single.exe**: קובץ אחד שנוח לשלוח לאחרים. נפתח מעט לאט יותר.

המאגר נשמר ב-`%LOCALAPPDATA%\Mechapes`.

**שימוש נייד (למשל בדיסק-און-קי):** יוצרים ליד התוכנה תיקייה ריקה בשם `MechapesData`, והמאגר יישמר בה.

> בפתיחה הראשונה Windows עשוי להציג אזהרה של SmartScreen, כי התוכנה לא חתומה דיגיטלית. לוחצים "מידע נוסף" ואז "הפעל בכל זאת".

## שימוש
1. **הוסף תיקייה…**: בוחרים תיקייה. התוכנה קוראת את כל הקבצים שבה ובונה מאגר. בפעם הראשונה זה לוקח זמן, ואחר כך מתעדכנים רק קבצים שהשתנו.
2. מסמנים ברשימה (☑/☐) באילו תיקיות לחפש.
3. מקלידים מילים ובוחרים מצב:
   - **כל המילים בקובץ**: כל המילים צריכות להופיע בקובץ, בכל מקום שהוא.
   - **בדילוג: עד N מילים בין מילה למילה**: המילים צריכות להופיע קרוב זו לזו. אם מסמנים **לפי הסדר**, הן צריכות להופיע גם בסדר שהוקלד.
   - **צירוף מדויק**: המילים צמודות זו לזו.
4. לחיצה על תוצאה מציגה את הקטעים שנמצאו, עם המילים מודגשות. לחיצה כפולה פותחת את הקובץ.
5. **קבצים שלא נקראו…**: רשימת הקבצים שלא נקראו והסיבה, עם כפתור לנסות שוב.

| סימן | משמעות | דוגמה |
|---|---|---|
| `*` | כל רצף אותיות | `ירושל*` |
| `?` | אות אחת | `כ?ב` |
| `\|` | אחת מכמה אפשרויות | `משה\|אהרן` |
| `-` | בלי המילה | `-טיוטה` |

**גם עם אותיות שימוש**: החיפוש `ספר` ימצא גם `והספר`, `בספר`, `שבספר` (עד שלוש אותיות מתוך ו,ה,ב,כ,ל,מ,ש בתחילת המילה). ניקוד, טעמים וגרשיים לא משפיעים על החיפוש.

## סוגי קבצים
docx, doc, rtf, odt, pdf, xlsx, xls, ods, csv, pptx, ppt, odp, eml, msg, mht, txt, html, epub, md, json, xml ועוד.

מגבלות:
- PDF סרוק (תמונה בלבד) לא נקרא, כי אין בו טקסט.
- קבצים מוגנים בסיסמה לא נקראים.
- קבצים מעל 200MB מדולגים, וקבצי טקסט מעל 30MB.
- קבצי OneDrive שנמצאים רק בענן מדולגים, כדי לא להוריד אותם. כדי לכלול אותם, לוחצים עליהם ימני ובוחרים "השאר תמיד במכשיר זה".
- אם תיקייה נמצאת בכונן מנותק (דיסק נייד או כונן רשת), המאגר שלה נשמר ולא נמחק.
- קובץ שתקוע יותר מ-2 דקות או מקריס את הקריאה מדולג ומופיע ברשימת הקבצים שלא נקראו.

## לפיתוח
```bash
pip install -r requirements.txt
```
```bash
python app.py
```
```bash
python -m pytest tests
```
בניית ‎.exe: `pyinstaller mechapes.spec`. הבנייה רצה גם אוטומטית ב-GitHub Actions (`.github/workflows/build-mechapes.yml`).

קריאת PDF נעשית עם PyMuPDF (רישיון AGPL). קוד המקור של התוכנה פתוח במאגר הזה.
