קשר טוב — תיקיית האתר

זוהי אפליקציית שרת עם מסד נתונים משותף (Cloudflare D1), ולא אתר שאפשר להפעיל בלחיצה כפולה על HTML.
האתר מיועד לפרסום בחשבון Cloudflare (המסלול החינמי מספיק), ראו "פרסום בענן" למטה.

── איך נכנסים (כמו בקבוצה במייל) ──
1. מי שרוצה להצטרף פותחת את כתובת האתר, רואה את דף הכניסה ולוחצת "שלחי בקשת הצטרפות במייל"
   (נפתח מייל מוכן למנהלת המרחב).
2. המנהלת מאשרת: נכנסת לאתר → "חברות המרחב" בתפריט → "הזמנת חברה חדשה" (שם + מייל).
   האתר מפיק קישור הזמנה אישי, והמנהלת שולחת אותו חזרה במייל (יש כפתור "שליחה במייל").
3. החברה פותחת את הקישור, בוחרת סיסמה ונכנסת. מכאן הכניסה היא עם מייל + סיסמה (הדף זוכר אותה 30 יום).
   הקישור חד-פעמי ותקף לשבוע. שכחה סיסמה? המנהלת לוחצת "קישור חדש" ליד שמה ושולחת שוב.
דרך מהירה לכל מי שכבר בקבוצה: המנהלת מדביקה ב"חברות המרחב" → "ייבוא רשימת מיילים" את כל הכתובות
   מהקבוצה (אפשר להעתיק את כל שדה "אל" של מייל בבת אחת) ושולחת את כתובת האתר בקבוצה.
   כל מי שברשימה נכנסת לכתובת, מזינה את המייל שלה, והאתר מבקש ממנה לבחור סיסמה — ונכנסת. בלי אישור
   פרטני ובלי קישור אישי. בפעמים הבאות אותו דף מבקש את הסיסמה.
   אפשרות נוספת: לשים את הכתובות בקובץ server/roster.json בריפו (רשימת מחרוזות, למשל ["שם <מייל>", "מייל"]);
   הן נוספות לרשימת החברות אוטומטית בפרסום הבא.
   אפשרות (לא חובה): לקבוע "קוד הצטרפות" משותף שחברות מהרשימה צריכות להזין בהרשמה הראשונה.
מנהלת יכולה גם להשבית חברה (מנותקת מיד), להסיר אותה, או להפוך חברה למנהלת נוספת.
אפשר כמה מנהלות; מנהלת מזמינה מנהלת נוספת בבחירת התפקיד "מנהלת" (אף אחת לא משנה את ההרשאה של עצמה).
כל שינוי בכרטיס נרשם עם שם החברה שביצעה אותו. הרזומות והנתונים מוגשים רק לחברות מחוברות.
אין צורך בשום חשבון חיצוני (לא ChatGPT ולא Google).

── פרסום בענן בלי טרמינל (מומלץ) ──
כל השלבים באתר של Cloudflare (dash.cloudflare.com, חשבון חינמי). הקוד נמשך ישירות מ-GitHub.
טיפ: אם Chrome מתרגם את הדף לעברית, בטלו את התרגום (אייקון התרגום בשורת הכתובת → "הצג את המקור"); התרגום משבש שמירת טפסים.
1. מסד נתונים: Storage & Databases → D1 SQL Database → Create → שם: kesher-tov.
   המזהה (Database ID) של המסד צריך להופיע בקובץ wrangler.jsonc שבריפו, בשורה "database_id".
   (המזהה של המסד שנוצר כבר נמצא שם; אם יוצרים מסד חדש, יש לעדכן את השורה הזו ב-GitHub.)
2. האתר: Workers & Pages → Create → Workers → Import a repository → חברו את GitHub ובחרו את הריפו ata.
   • Project name: ata (ברירת המחדל, כשם הריפו; שם אחר דורש לעדכן את "name" ב-wrangler.jsonc)
   • Branch: הענף שבו הקוד (למשל claude/hopeful-cannon-j39req, או main אחרי מיזוג)
   • Build command:  pnpm build
   • Deploy command: npx wrangler deploy   (זו ברירת המחדל)
   • אין צורך במשתני בנייה.
   לחצו Create and deploy (או Save and deploy / Retry build בפרויקט קיים). הבנייה אורכת 2–4 דקות.
   בסיום, בלשונית Overview של ה-Worker, מופיעה הכתובת: https://ata.<חשבון>.workers.dev
3. הקמה: פתחו את הכתובת בדפדפן. הטבלאות במסד נוצרות לבד, וכל עוד אין אף חברה האתר מציג "דף הקמה":
   שם, מייל וסיסמה למנהלת הראשונה. מכאן הכול מתנהל מתוך האתר (הזמנת חברות ב"חברות המרחב").
עדכון גרסה בהמשך: כל דחיפה (push) לענף שנבחר מפורסמת אוטומטית.
אופציונלי: Settings של ה-Worker → Variables and Secrets → KESHER_CONTACT_EMAIL — לאיזה מייל נשלחות בקשות הצטרפות (ברירת מחדל: המנהלת הראשונה).

── פרסום מהטרמינל (חלופה למפתחים) ──
pnpm install → npx wrangler login → pnpm deploy. פתחו את הכתובת שהודפסה: דף ההקמה יוצר את המנהלת הראשונה.
(חילוץ אם כל המנהלות ננעלו בחוץ: node scripts/invite.mjs <email> "<שם>" --url https://<כתובת>)

── הפעלה מקומית למפתח ──
pnpm install → pnpm build → pnpm start (מריץ את הגרסה הבנויה על 127.0.0.1:8787; הטבלאות נוצרות לבד)
יצירת מנהלת מקומית: node scripts/invite.mjs you@example.com "שם" --local
לפיתוח שוטף: pnpm dev (ראו .dev.vars.example למשתני הסביבה המקומיים).
בדיקות: pnpm test

── קבצים מרכזיים ──
ui/index.html — מבנה הממשק בעברית.
public/style.css — העיצוב (ערכת צבעים אחת, מוגדרת בראש הקובץ).
public/app.js — תצוגה, חיפוש, סינון, טפסים וניהול חברות.
public/shared.js — סנכרון ושמירה בשרת.
worker/index.ts — שער הכניסה: דפי כניסה/הזמנה ובדיקת התחברות לפני כל בקשה.
server/auth.mjs — סיסמאות, הפעלות, הזמנות ודפי הכניסה.
server/access.mjs — ניהול חברות על ידי מנהלות.
server/records.mjs — טיפול במאגר המשותף.
server/seed.json — 222 רשומות המקור (אינו צילום עדכני של האתר החי).
public/documents — הרזומות המקוריים.
drizzle/ — סכמת מסד הנתונים והמיגרציות (רצות מתוך האתר, server/migrate.mjs).
wrangler.jsonc — הגדרות ה-Worker ומזהה מסד הנתונים ב-Cloudflare.

כדי לקבל גם את הנתונים העדכניים מהאתר הישן: פתחו אותו ולחצו "גיבוי המאגר", ואז ייבאו את קובץ ה-JSON באתר החדש.
