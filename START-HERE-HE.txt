קשר טוב — תיקיית האתר

זוהי אפליקציית שרת עם מסד נתונים משותף (Cloudflare D1), ולא אתר שאפשר להפעיל בלחיצה כפולה על HTML.
אין להעלות את התיקייה כפי שהיא ל-Netlify Drop: כדי לשמור על סנכרון בין המשתמשות נדרש שרת תואם וחיבור למסד הנתונים.

── הגנה על המאגר (חובה לפני פרסום) ──
האתר דורש התחברות עם חשבון ChatGPT, ורק כתובות מייל שמופיעות ברשימת הגישה יכולות להיכנס.
בלי רשימת גישה האתר נעול לכולן ומציג דף הסבר עם הכתובת שאיתה התחברת.
יש שתי דרכים להגדיר את הרשימה (אפשר גם את שתיהן):
1. משתנה סביבה בשם KESHER_ALLOWED_EMAILS עם הכתובות מופרדות בפסיק, למשל:
   rivka@example.com, sara@example.com
2. הקובץ server/allowed-emails.json — רשימת כתובות בפורמט JSON, למשל:
   ["rivka@example.com", "sara@example.com"]
   לאחר עריכת הקובץ יש לפרסם מחדש.
כל שינוי בכרטיס נרשם יחד עם שם המשתמשת שביצעה אותו, ומוצג בתחתית הכרטיס המלא.
הרזומות המקוריים (public/documents) וקובצי הנתונים מוגשים רק למשתמשות מחוברות ומאושרות.

── הפעלה מקומית למפתח ──
1. התקינו Node.js בגרסה 22.13 ומעלה ו-pnpm בגרסה המצוינת ב-package.json.
2. פתחו מסוף בתיקייה והפעילו pnpm install ולאחר מכן pnpm dev.
   בסביבת הפיתוח יש התחברות מדומה: פתחו /signin-with-chatgpt כדי "להתחבר" בתור seedy@sites.test,
   והוסיפו את הכתובת הזו לרשימת הגישה (למשל ב-server/allowed-emails.json) כדי לראות את המאגר.
3. בנייה לפרסום: pnpm build. הפרסום מחייב הגדרת מסד נתונים והרצת הסכמות שבתיקיית drizzle
   (כולל 0002_mysterious_whistler.sql שמוסיף את עמודות "מי עדכנה").
4. בדיקות: node check-import.cjs · node check-docx.cjs · node --input-type=module -e "import('./check-shared.mjs')"
   בדיקה של הגרסה הבנויה עם wrangler: pnpm start (ראו .dev.vars.example למשתני הסביבה המקומיים).

── קבצים מרכזיים ──
ui/index.html — מבנה הממשק בעברית.
public/style.css — העיצוב (ערכת צבעים אחת, מוגדרת בראש הקובץ).
public/app.js — תצוגה, חיפוש, סינון וטפסים.
public/shared.js — סנכרון ושמירה בשרת.
worker/index.ts — שער הכניסה: בודק התחברות והרשאה לפני כל בקשה.
server/auth.mjs — זיהוי המשתמשת ורשימת הגישה.
server/records.mjs — טיפול במאגר המשותף.
server/seed.json — 222 רשומות המקור (אינו צילום עדכני של האתר החי).
public/documents — הרזומות המקוריים.

כדי לקבל גם את הנתונים העדכניים: פתחו את האתר ולחצו "גיבוי המאגר" ושמרו את קובץ הגיבוי לצד תיקייה זו.
הארכיון אינו כולל סיסמאות, מפתחות גישה או תיקיית node_modules.
