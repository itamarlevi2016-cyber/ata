קשר טוב — תיקיית האתר

זוהי אפליקציית שרת עם מסד נתונים משותף (Cloudflare D1), ולא אתר שאפשר להפעיל בלחיצה כפולה על HTML.
האתר מיועד לפרסום בחשבון Cloudflare (המסלול החינמי מספיק), ראו "פרסום בענן" למטה.

── איך נכנסים (כמו בקבוצה במייל) ──
1. מי שרוצה להצטרף פותחת את כתובת האתר, רואה את דף הכניסה ולוחצת "שלחי בקשת הצטרפות במייל"
   (נפתח מייל מוכן למנהלת המרחב).
2. המנהלת מאשרת: נכנסת לאתר → "חברות המרחב" בתפריט → "הזמנת חברה חדשה" (שם + מייל).
   האתר מפיק קישור הזמנה אישי, והמנהלת שולחת אותו חזרה במייל (יש כפתור "שליחה במייל").
3. החברה פותחת את הקישור, בוחרת סיסמה ונכנסת. מכאן הכניסה היא עם מייל + סיסמה (הדף זוכר אותה 30 יום).
   הקישור חד-פעמי ותקף לשבוע. שכחה סיסמה? המנהלת לוחצת "קישור חדש" ליד שמה ושולחת שוב.
מנהלת יכולה גם להשבית חברה (מנותקת מיד), להסיר אותה, או להפוך חברה למנהלת נוספת.
כל שינוי בכרטיס נרשם עם שם החברה שביצעה אותו. הרזומות והנתונים מוגשים רק לחברות מחוברות.
אין צורך בשום חשבון חיצוני (לא ChatGPT ולא Google).

── פרסום בענן בלי טרמינל (מומלץ) ──
כל השלבים באתר של Cloudflare (dash.cloudflare.com, חשבון חינמי). הקוד נמשך ישירות מ-GitHub.
1. מסד נתונים: בתפריט השמאלי Storage & Databases → D1 SQL Database → Create → שם: kesher-tov → Create.
   בעמוד שנפתח מופיע Database ID — לחצו Copy.
2. האתר: Workers & Pages → Create → לשונית Workers → Import a repository → חברו את חשבון GitHub ובחרו את הריפו ata.
   בהגדרות הפרויקט:
   • Project name: kesher-tov   (חייב להיות בדיוק כך)
   • Branch: הענף שבו הקוד (למשל claude/hopeful-cannon-j39req, או main אחרי מיזוג)
   • Build command:  pnpm build
   • Deploy command: npx wrangler d1 migrations apply DB --remote --config dist/server/wrangler.json && npx wrangler deploy --config dist/server/wrangler.json
   • Build variables (Variables and Secrets / Environment variables של ה-build): הוסיפו משתנה
     KESHER_D1_ID  =  ה-Database ID שהועתק בשלב 1
   לחצו Create and deploy. הבנייה הראשונה אורכת 2–4 דקות; בסיום מוצגת כתובת: https://kesher-tov.<חשבון>.workers.dev
3. הקמה: פתחו את הכתובת בדפדפן. כל עוד אין אף חברה, האתר מציג "דף הקמה": שם, מייל וסיסמה למנהלת הראשונה.
   מכאן הכול מתנהל מתוך האתר (הזמנת חברות ב"חברות המרחב").
עדכון גרסה בהמשך: כל דחיפה (push) לענף שנבחר מפורסמת אוטומטית.
אופציונלי: Settings של ה-Worker → Variables and Secrets → KESHER_CONTACT_EMAIL — לאיזה מייל נשלחות בקשות הצטרפות (ברירת מחדל: המנהלת הראשונה).

── פרסום מהטרמינל (חלופה למפתחים) ──
דרישות: Node.js 22.13 ומעלה, pnpm (גרסה ב-package.json), וחשבון Cloudflare.
1. pnpm install
2. npx wrangler login
3. npx wrangler d1 create kesher-tov       (מדפיס database_id)
4. KESHER_D1_ID=<database_id> pnpm deploy  (ב-Windows PowerShell: $env:KESHER_D1_ID="<id>"; pnpm deploy)
5. פתחו את הכתובת שהודפסה: דף ההקמה יוצר את המנהלת הראשונה. (חלופה/חילוץ: node scripts/invite.mjs <email> "<שם>" --url https://<כתובת>)

── הפעלה מקומית למפתח ──
pnpm install → pnpm build → pnpm d1:migrate:local → pnpm start (מריץ את הגרסה הבנויה על 127.0.0.1:8787)
יצירת מנהלת מקומית: node scripts/invite.mjs you@example.com "שם" --local
לפיתוח שוטף: pnpm dev (ראו .dev.vars.example למשתני הסביבה המקומיים).
בדיקות: pnpm test

── קבצים מרכזיים ──
ui/index.html — מבנה הממשק בעברית.
public/style.css — העיצוב (ערכת צבעים אחת, מוגדרת בראש הקובץ).
public/app.js — תצוגה, חיפוש, סינון, טפסים וניהול חברות.
public/shared.js — סנכרון ושמירה בשרת.
worker/index.ts — שער הכניסה: דפי כניסה/הזמנה ובדיקת התחברות לפני כל בקשה.
server/auth.mjs — סיסמאות, הפעלות, הזמנות ודפי הכניסה.
server/access.mjs — ניהול חברות על ידי מנהלות.
server/records.mjs — טיפול במאגר המשותף.
server/seed.json — 222 רשומות המקור (אינו צילום עדכני של האתר החי).
public/documents — הרזומות המקוריים.
drizzle/ — סכמת מסד הנתונים והמיגרציות (מורצות אוטומטית ב-pnpm deploy).

כדי לקבל גם את הנתונים העדכניים מהאתר הישן: פתחו אותו ולחצו "גיבוי המאגר", ואז ייבאו את קובץ ה-JSON באתר החדש.
