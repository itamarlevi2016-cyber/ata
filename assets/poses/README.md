# תמונות תנוחה של ר' דוד (אופציונלי)

הדמות באתר היא האיור המקורי, חתוך לשכבות ומונפש: ראש, גוף, פה, עיניים ואפקטים.
הידיים באיור משולבות ולכן אינן זזות. כדי שר' דוד יעשה תנועות ידיים אמיתיות, אפשר ליצור באותו כלי שיצר את האיור
תמונות של אותה דמות בתנוחות נוספות, ולהוסיף אותן כאן.

## איך מוסיפים
1. יוצרים תמונה של הדמות (אותו איור, אותה מסגרת של כל הגוף, אותו רקע בז'). הגודל הרצוי זהה לאיור המקורי: **832×1248**.
2. שומרים אותה בתיקייה הזו בשם שמתאים לתנועה, למשל `wave.webp`. מותר גם `png` או `jpg`.
3. רושמים אותה בקובץ `manifest.json`, למשל:
   ```json
   { "wave": "wave.webp", "point": "point.webp" }
   ```
4. זהו. בשלבים עם התנועה הזו האתר יציג את התמונה במקום הדמות המונפשת.

## התנועות שכדאי ליצור (הנחיה לכלי היצירה)
תבנית: *"אותה דמות בדיוק כמו בתמונת המקור, אותו סגנון איור ואותו רקע בז', הדמות כולה, אבל …"*

| שם הקובץ | מה הדמות עושה |
|---|---|
| `wave` | מנופף בשלום ביד ימין, מחייך |
| `point` | מצביע בקצה האצבע כלפי מעלה, כמו מעלה נקודה חשובה |
| `present` | שתי הידיים פתוחות לצדדים, כף יד כלפי מעלה, מזמין |
| `palm` | כף יד אחת פתוחה קדימה, כמו "עצור" או "שימו לב" |
| `jaw` | שתי האצבעות נוגעות בצדדי הלסת, פה פתוח |
| `straw` | מחזיק קשית שתייה ליד הפה |
| `hum` | יד אחת על החזה, עיניים עצומות קלות, פה סגור |
| `siren` | יד אחת מורמת גבוה כלפי מעלה, כמו מסמן צליל עולה |
| `project` | יד פשוטה קדימה, פה פתוח, כמו מדבר אל קהל גדול |
| `cheer` | שתי הידיים מורמות באוויר, חיוך רחב |
